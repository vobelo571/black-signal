WTTG3 MERRAMUN — НОУТБУК В БУНКЕРЕ УЧЁНЫХ

1. Включите мод в MO2 и полностью перезапустите игру.
2. Загрузите сохранение и придите в бункер учёных на Янтаре.
3. В боковой части бункера на металлической тумбе автоматически появится
   закреплённый ноутбук Merramun (работает и в существующих сейвах).
4. Наведитесь на ноутбук и нажмите клавишу взаимодействия — появится
   подсказка «Играть в казино».
5. Стрелки меняют ставку, центральная кнопка запускает вращение.
6. Esc закрывает игру после завершения текущего оплаченного спина.

Интеграция с КПК полностью удалена: вкладки, кнопки и горячей клавиши нет.
Ноутбук создаётся один раз, его идентификатор хранится в сохранении.
При установленном Interaction Dot Marks ноутбук получает интерактивную
точку-маркер того же типа, что тайники и другие используемые объекты.
Без Interaction Dot Marks остаётся стандартная подсказка взаимодействия.

Ставки: 100 / 200 / 500 / 2500 / 5000 RU.
Они повторяют оригинальное соотношение 1 / 2 / 5 / 25 / 50.

Вероятности исходов взяты из DA_WinType_99-RTP игры Welcome to the Game III
и намеренно не вынесены в настройки.

Интерфейс адаптирован под отдельное полноэкранное окно и центрирован на экране.

Логика вращения:
- оригинальный шанс выигрышного спина 25%;
- оригинальная сетка 6 колонок на 5 рядов (30 символов);
- комбинация начинается от 8 одинаковых символов;
- выигрышные символы подсвечиваются оригинальным flipbook-эффектом;
- после подсветки исчезают только выигрышные символы;
- остальные символы сохраняются и падают вниз внутри своих колонок;
- новые символы добавляются исключительно в освободившиеся клетки сверху;
- каскады продолжаются до завершения подготовленного исхода;
- деньги начисляются только после окончания всей цепочки.

Используются оригинальные интервалы падения, таблица DA_WinType_99-RTP,
изображения, flipbook-кадры и звуки Welcome to the Game III.
Короткие звуки перекодированы в совместимый с X-Ray формат 44,1 kHz mono.

Таблица выплат за одно совпадение (8–9 / 10–11 / 12+ символов):
- Scroll: x0.2 / x0.5 / x2
- Urn: x0.4 / x0.9 / x4
- Disc: x0.5 / x1 / x5
- Ankh: x0.8 / x1.2 / x8
- Eye: x1 / x1.5 / x10
- Cobra: x1.5 / x2 / x12
- Falcon: x2 / x5 / x15
- Cat: x2.5 / x10 / x25
- Anubis: x10 / x25 / x50

Выплата спина равна сумме множителей реально исчезнувших комбинаций,
умноженной на выбранную ставку. Она больше не выбирается случайным числом
из диапазона исхода.

Пирамида-множитель не добавляется в обычный проигрышный спин. В оригинальных
WinOutcome её доля равна нулю для LV00 и начинается с LV01. Поэтому увидеть
её можно примерно в 7,55% всех спинов при исходном шансе выигрыша 25%.
Количество пирамид ограничивается исходными MaximumMultSymbolsCount.
Число на пирамиде является её реальным множителем, а несколько пирамид
перемножаются. Значения откалиброваны по уровням исходов таблицы 99-RTP;
контрольная симуляция 500 000 спинов даёт среднюю расчётную отдачу около 100%.
