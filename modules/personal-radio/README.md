# Личное радио КПК

BLACK SIGNAL · by @Flixmo · 1.0.0

Личный плейлист, сохранение трека и состояния, импортёр музыки.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.

**Необязательно:** [Python 3.10+ for Windows (with Tk)](https://www.python.org/downloads/windows/), [FFmpeg](https://ffmpeg.org/download.html).

Музыка и FFmpeg не включены. Импортёр: Python 3.10+ с Tk и FFmpeg. Импортировать свои треки до запуска игры. PDA Radio Extended не требуется: музыка и материалы Starcry_ не включены.

**Авторы:** FLX; штатный PDA-плеер Anomaly — Tronex. Личная музыка в архив не входит.

Исходные инструкции и уведомления сохранены в upstream-docs/.

Для своей музыки запустите FLX Radio Importer.py в папке установленного мода (Python 3.10+ с Tk и FFmpeg). Треки добавляются в gamedata/sounds/radio/_playlist_5.
