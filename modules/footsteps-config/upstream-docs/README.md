# NPC Audible Footsteps - Flixmo

Выделенная настройка шагов NPC из мода Oleh, автор исходного конфига — oleh5230.

Ходьба: сила шага 0.7; бег: 1.0; движение присев: 0.4–0.6.
Исправляет переопределения step_params у sim_default_bandit_3, sim_default_bandit_4,
sim_default_duty_1, sim_default_monolith_1 и sim_default_greh_4.

Использует штатные звуки поверхностей. Не требует включённого Oleh.
Не меняет шаги игрока и не включает отдельные скрипты сервоприводов экзоскелета.
Исходный конфиг перенесён без изменения параметров.
Имя файла сохранено для корректного перекрытия Oleh без двойной загрузки секции.

Включить в MO2 и поставить ниже Oleh в левой панели (более высокий приоритет).
В профиле G.A.M.M.A мод уже включён. Перезапустить MO2, если список не обновился,
затем полностью перезапустить игру. Новая игра не требуется.

Проверка в игре: загрузить сохранение рядом с патрулём, отвернуться от NPC
и сравнить шаги при ходьбе и беге. Фактическая слышимость в игре не проверена.
