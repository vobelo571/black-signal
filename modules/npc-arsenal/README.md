# Арсенал NPC

BLACK SIGNAL · by @Flixmo · 1.3.0

Оружие обычных NPC по рангу; повторная выдача потерянного оружия. Квестовые и уникальные персонажи сохраняют комплекты.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.
- [Modded Exes / DLTX](https://github.com/themrdemonized/xray-monolith/releases) — themrdemonized and contributors.

Броня не ограничивает выдачу. Фракции задают предпочтения, но не запрещают подходящие по рангу модели. В каталоге 367 моделей; работает с новыми и существующими NPC. После установки полностью перезапустите игру. Версия проверена автономно; игровой прогон ещё не выполнен.

**Авторы:** Доработки — @Flixmo; базовые системы и ресурсы — Anomaly / GAMMA и их авторы.

Исходные инструкции и уведомления сохранены в upstream-docs/.
