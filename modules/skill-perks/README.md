# Полезные эффекты навыков

BLACK SIGNAL · by @Flixmo · 0.1.1

Пассивные эффекты и множители опыта по уровням навыков.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.
- [Anomaly Skill System](https://www.moddb.com/mods/stalker-anomaly/addons/anomaly-skill-system) — HarukaSai.
- [Mod Configuration Menu (MCM)](https://www.moddb.com/mods/stalker-anomaly/addons/anomaly-mod-configuration-menu) — RavenAscendant and contributors.
- [G.A.M.M.A. Enhanced Recoil](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and contributors.

Первая тестовая версия. Содержит override Enhanced Recoil текущей GAMMA.

**Авторы:** FLX; Skill System — HarukaSai, Enhanced Recoil — Grokitach и участники GAMMA.

Исходные инструкции и уведомления сохранены в upstream-docs/.
