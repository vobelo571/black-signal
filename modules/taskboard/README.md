# Taskboard: редакция FLX

BLACK SIGNAL · by @Flixmo · 2026.10.25

Группировка заданий, накопительные бонусы, метки и настраиваемая сдача.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.
- [Mod Configuration Menu (MCM)](https://www.moddb.com/mods/stalker-anomaly/addons/anomaly-mod-configuration-menu) — RavenAscendant and contributors.

Основа — iTheon PDA Taskboard. Установить после оригинального Taskboard и его патчей.

**Авторы:** FLX; основа PDA Taskboard — iTheon.

Исходные инструкции и уведомления сохранены в upstream-docs/.
