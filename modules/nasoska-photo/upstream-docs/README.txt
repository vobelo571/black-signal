Ycatan_ - Nasoska Photo

Фотография любомой насоски — отдельный мод для GAMMA.

Иконка занимает исходную маленькую ячейку 1x1.
Заменяет название, описание, иконку picture_woman и снимок в анимации осмотра.
Изображение пользователя сохранено целиком, без обрезки; рамка исходной фотографии оставлена.
Требуется включённый 443- Photo of a Loved One Animated - Apathy_Knight для анимации.
В Mod Organizer 2 включить этот мод и расположить ниже исходного мода и модов иконок.
В архиве папка gamedata находится в корне для установки через MO2.
Отключение мода возвращает исходный предмет. Новая игра не требуется.
Написание «любомой» сохранено по запросу.
Проверены DDS и XML. Проверка непосредственно в игре не выполнялась.
