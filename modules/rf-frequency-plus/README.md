# RF-Частота+

BLACK SIGNAL · by @Flixmo · 1.0.2

Активные частоты заданий и районы поиска в подсказке ресивера.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.

RF-задания берутся из установленной GAMMA; собственных заданий не создаёт.

**Авторы:** Доработки — @Flixmo; базовые системы и ресурсы — Anomaly / GAMMA и их авторы.

Исходные инструкции и уведомления сохранены в upstream-docs/.
