RF-Частота+ — 1.0.2

При наведении на RF-ресивер в инвентаре показывает:
  Заряд: 100%

  Компактный RF-приёмник для поиска источников радиосигнала.
  Настройте нужную частоту и ориентируйтесь по усилению сигнала.

  Активные частоты:
  1) Свалка 145 МГц - Юго-запад
  2) Кладбище техники 220 МГц - Северо-запад
Числа выше — только пример. В игре берутся текущие частоты вашего сохранения.

Источники:
- Активная RF-посылка Tweaki_Breeki / Cookbook / G.A.M.M.A. Economy.
  Район берётся из исходных данных задания по сохранённым вершинам места
  появления, поэтому совпадает с сообщением о посылке.
- Принятые задания с сохранёнными полями freq и map, включая поиск пропавшего
  отряда (tasks_fate). Район читается из текущего описания задания, если указан.
  Иначе выводится «Район не указан». Завершённые, отменённые и готовые к сдаче
  задания поиска отряда исключаются. Подобранные предметы исключаются сразу.

Частоты текущей локации идут первыми. Список обновляется при новом наведении.
Если заданий нет, появляется «Нет активных RF-заданий».
Вместо длинного описания показана короткая справка, ниже — список частот.
Стоимость и блок особенностей ресивера убраны.
Название и вес остаются штатными. Подсказки остальных предметов не меняются.

Установка: включите «RF-Частота+» в левой панели Mod Organizer 2.
Мод содержит отдельный скрипт и собственные строки RU/EN, не заменяет ui_item,
item_radio, task_manager или TB_RF_Receiver_Packages и не меняет сохранения.
Совместим с установленными RF-модами и модами подсказок G.A.M.M.A.
При уже запущенной игре нужен её перезапуск. Новая игра не требуется.
Удаление: отключите мод в Mod Organizer 2.

1.0.2: исправлено чтение активной посылки из строчного пространства имён
tb_rf_receiver_packages. Добавлено чтение района из описания задания и
резервное чтение района из сообщения о посылке.
