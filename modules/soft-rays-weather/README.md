# Мягкие лучи и спокойная погода

BLACK SIGNAL · by @Flixmo · 1.0

Мягкие лучи, сокращённые выборки шейдеров, ослабление дождя и отключение Airborne Pulse.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.
- [Screen Space Shaders](https://www.moddb.com/mods/stalker-anomaly/addons/screen-space-shaders) — Ascii1457.

Патч текущих DX11/r3-шейдеров. Не устанавливает 4K-паки и не меняет user.ltx или MCM. Результат на других версиях SSS не проверен.

**Авторы:** FLX; Screen Space Shaders — Ascii1457; исходные погодные файлы — Anomaly / GAMMA.

Исходные инструкции и уведомления сохранены в upstream-docs/.
