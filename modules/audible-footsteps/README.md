# Слышимые шаги врагов

BLACK SIGNAL · by @Flixmo · 1.0.0

Пространственный звук движущихся врагов из звуковой части Fireteam.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.
- [G.A.M.M.A. Footsteps](https://github.com/Grokitach/Stalker_GAMMA) — GAMMA contributors; see installed addon credits.

Не включать вместе с полным Fireteam AI; дополнительные шаги могут суммироваться с обычными.

**Авторы:** FLX / Fireteam AI; звуковые сэмплы — G.A.M.M.A. Footsteps.

Исходные инструкции и уведомления сохранены в upstream-docs/.
