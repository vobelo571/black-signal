# BLACK SIGNAL — Калибр: снабженец Янтаря

**by @Flixmo**

Модуль `yantar-hunter` · версия **1.0.0**.

Торговец противомутантными боеприпасами с пятью ступенями репутации.

## Обязательные зависимости

- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team. Целевая среда всех модулей — установленная GAMMA 0.9.5 из авторского профиля; отдельный ZIP означает независимую установку модуля, а не совместимость с чистой Anomaly.
- [Modded Exes / DLTX](https://github.com/themrdemonized/xray-monolith/releases) — themrdemonized and contributors. Используйте совместимый движок из своей GAMMA. Не заменяйте EXE только ради этого пака.
- [Hideout Furniture](https://www.moddb.com/mods/stalker-anomaly/addons/hideout-furniture-hf) — Aoldri. Референс: 2.3.2. Базовая система мебели для зависимых дополнений.
- [Hideout Furniture Expansion](https://www.moddb.com/mods/stalker-anomaly/addons/hideout-furniture-expansion) — maidresidence, HarukaSai, Frogs, Raven. Референс: 1.0.2. Модели и секции декора, используемые сценами новых NPC.
- [Even More Hideout Furniture](https://www.moddb.com/mods/stalker-anomaly/addons/even-more-hideout-furniture) — facelessez. Референс: 2.2. Дополнительный декор сцен Янтаря; установить также базовую мебель.

## Установка

1. Закройте игру и сделайте резервную копию сохранений.
2. Установите этот ZIP через Mod Organizer 2 как отдельный мод.
3. Включите зависимости, затем этот модуль. В левой панели поставьте его ниже базовых модов, чтобы его файлы имели больший числовой приоритет.
4. Отключите старую отдельную копию этого же модуля, если она уже установлена.
5. Полностью перезапустите игру через MO2.

Ассортимент рассчитан на текущую баллистику GAMMA; для чистой Anomaly не заявлен.

Устанавливайте либо отдельный ZIP, либо тот же компонент общего пака: не включайте две копии одновременно.

Сторонние библиотеки не включены; ссылки выше ведут на страницы авторов. Не обновляйте библиотеки внутри GAMMA без проверки совместимости.
