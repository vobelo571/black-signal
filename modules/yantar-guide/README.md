# Ориентир: проводник Янтаря

BLACK SIGNAL · by @Flixmo · 1.0.1

Постоянный проводник с восемью платными маршрутами и подтверждением оплаты.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.
- [Modded Exes / DLTX](https://github.com/themrdemonized/xray-monolith/releases) — themrdemonized and contributors.
- [Hideout Furniture](https://www.moddb.com/mods/stalker-anomaly/addons/hideout-furniture-hf) — Aoldri.
- [Hideout Furniture Expansion](https://www.moddb.com/mods/stalker-anomaly/addons/hideout-furniture-expansion) — maidresidence, HarukaSai, Frogs, Raven.
- [Even More Hideout Furniture](https://www.moddb.com/mods/stalker-anomaly/addons/even-more-hideout-furniture) — facelessez.

Поддержка существующих сохранений предусмотрена модулем.

**Авторы:** FLX; базовые модели и мебель — Anomaly / GAMMA, Aoldri, maidresidence, HarukaSai, facelessez и соавторы.

Исходные инструкции и уведомления сохранены в upstream-docs/.
