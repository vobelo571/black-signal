# Колесо еды и медикаментов

BLACK SIGNAL · by @Flixmo · 1.0.0.0

Автозаполнение QAW едой и медициной.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.
- [Quick Action Wheel](https://www.moddb.com/mods/stalker-anomaly/addons/quick-action-wheel) — HarukaSai.

Отключить G.A.M.M.A. Quick Action Wheel Balance; базовый Quick Action Wheel оставить включённым.

**Авторы:** FLX; Quick Action Wheel — HarukaSai.

Исходные инструкции и уведомления сохранены в upstream-docs/.
