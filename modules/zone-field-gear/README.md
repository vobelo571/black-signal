# Снаряжение Зоны

BLACK SIGNAL · by @Flixmo · 0.7.1

32 фракционных костюма: восемь семейств, модели, руки, иконки и баланс.

**Установка:** ZIP → Mod Organizer 2 → включить ниже базовых модов → перезапустить игру.

**Требуется:**
- [G.A.M.M.A. / Anomaly 1.5.3](https://github.com/Grokitach/Stalker_GAMMA) — Grokitach and the Anomaly team.
- [Modded Exes / DLTX](https://github.com/themrdemonized/xray-monolith/releases) — themrdemonized and contributors.

При удалении сначала убрать добавленные предметы или вернуться к сохранению до установки. Основы: Anomaly, Blackgrowl, IENCE, LASS; см. CREDITS.

**Авторы:** FLX; основы Anomaly и Blackgrowl, руки IENCE / THAP, базовые текстуры LASS; blender-xray — PavelBlend.

Исходные инструкции и уведомления сохранены в upstream-docs/.
