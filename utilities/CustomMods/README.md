# BLACK SIGNAL — CustomMods

**by @Flixmo**. Утилита сохранения списка пользовательских модов при обновлении GAMMA.

1. Скопировать содержимое этого архива в `<GAMMA>/_tools/CustomMods/`.
2. Полностью закрыть MO2, затем запустить `1_SAVE_before_GAMMA_update.cmd`.
3. Обновить GAMMA, снова закрыть MO2 и запустить `2_RESTORE_after_GAMMA_update.cmd`.

Внешних библиотек не нужно: Windows PowerShell 5.1 встроен в Windows.
Скрипт ожидает портативную GAMMA и профиль **G.A.M.M.A**; для другого профиля
изменить `$profileName` в `Custom-Mods.ps1` перед использованием.

Скрипт создаёт резервные копии перед изменением `modlist.txt`. В этот архив
не включены личный список модов и резервные копии автора.
Исходная подробная инструкция: `README_RU.txt`.
