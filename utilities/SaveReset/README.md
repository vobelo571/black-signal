# BLACK SIGNAL — SaveReset

**by @Flixmo**. Отдельная программа для Windows x64.
Обнуляет счётчики смертей и выставляет две жизни в поддерживаемых `.scoc`,
предварительно сохраняя копии `.scoc`, `.scop` и `.dds`. Неподдерживаемые файлы пропускает.

Закройте игру. Программу нельзя применять к единственной копии ценных сохранений.
Исходная инструкция сохранена в `README-original.txt`.

Зависимость для сборки: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
Сборка в каталоге `src`:

```powershell
dotnet publish SaveReset.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ../bin
```

Готовый self-contained EXE не требует отдельной установки .NET Runtime.
В основной Git-репозиторий большой EXE не включается; исходники распространяются отдельно.
`global.json` фиксирует исходный SDK 8.0.413. При использовании другого SDK
изменить его осознанно или установить соответствующую версию.

Исходный код сохранён без изменения алгоритма редактора. При подготовке пака
сохранения пользователя не открывались для записи и не обрабатывались.
