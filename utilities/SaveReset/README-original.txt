GAMMA SaveReset

1. Закройте игру.
2. Запустите SaveReset.exe.
3. Выберите папку savedgames (по умолчанию D:\Anomaly\appdata\savedgames).
4. Нажмите «Обнулить смерти и установить 2 жизни».

Обрабатываются все .scoc в папке, без вложенных папок.
Поля: ironman.death_count = 0, ironman.death_limit = 2,
ironman.granted_lives = 0, statistics.deaths = 0.
Другие параметры, в том числе автоматическая выдача жизней по игровому времени, не меняются.

Резервные копии .scoc, .scop и .dds и отчёты находятся в SaveReset_Backups.
Для восстановления при закрытой игре скопируйте файлы из нужной папки резервной копии обратно в savedgames с заменой.
Сейвы неподдерживаемого формата пропускаются, причина показывается в окне.
Программа автономная, для Windows x64; отдельная установка .NET не нужна.
Исходники и проект: src. Результат проверки: test-report.txt.
