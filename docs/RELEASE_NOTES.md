BLACK SIGNAL — by @Flixmo

Первый интеграционный кандидат модульной коллекции для G.A.M.M.A. / Anomaly 1.5.3.

28 модулей доступны по отдельности; общий архив `BLACK-SIGNAL-0.1.0-rc.1-MO2.zip`
позволяет выбрать компоненты в MO2. Внутри каждого отдельного ZIP есть описание,
установка, авторы и ссылки на необходимые библиотеки. Сторонние библиотеки
и личная музыка не включены.

Целевая база — авторский профиль GAMMA 0.9.5. Это prerelease: полная интеграция
в игровом движке ещё требует проверки. Перед установкой сделать резервную копию
сохранений; отключить старые отдельные копии тех же модулей.

QAW-модуль требует отключить GAMMA Quick Action Wheel Balance. Audible NPC
Footsteps Plus не включать вместе с полным Fireteam AI. Графические компоненты
рассчитаны на DX11/r3. Новые предметы, NPC и изменения оружия могут остаться
в сохранении после отключения файлов мода.
