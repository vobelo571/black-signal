# Проверка кандидата 04.11.2026

Проверена подготовка файлов, а не работоспособность всех модулей в одном
игровом сохранении. В установленной игре файлы и порядок модов не изменялись.

- Все 45 действующих Lua-скриптов компилируются LuaJIT 2.1 / Lua 5.1.
- 80 XML-файлов проверены с учётом двух include-only входных файлов Anomaly.
- Между 28 модулями нет совпадающих путей `gamedata` без учёта регистра Windows.
- Исходные контрольные суммы сохранены; игровые файлы перенесены без изменений,
  кроме явно описанной ниже упаковочной правки Personal Radio.
- Подготовлены структура FOMOD, необязательные компоненты и машинный реестр зависимостей.
- PowerShell-синтаксис CustomMods проверен без запуска его операций.
- SaveReset собран из исходников с SDK .NET 8.0.413 в self-contained Windows x64.
  В рамках подготовки пака сохранения не менялись. Ранее проведённые авторские
  игровые проверки отдельных модулей не выдаются за новый тест всей интеграции.

## Изменение Personal Radio для публичного архива

Музыкальные треки исключены. Добавлен `.keep`, сохраняющий папку пустого плейлиста.
Инициализация плеера теперь рассматривает только файлы `.ogg` без учёта регистра,
чтобы не пытаться воспроизвести этот маркер или текстовый файл. При отсутствии
музыки задана строка для беззвучного стандартного ресурса `radio/no_sound`.

На настоящем блоке инициализации с небольшими заменами API движка проверены:
пустой список, только `.keep`, смесь `.keep`/TXT/двух OGG с разным регистром расширения.
Команда: `python tools/test_radio_playlist.py` (для QA нужен `lupa.luajit21`).

## Границы проверки

Реальный мастер MO2, внешний вид всех сцен, запуск всех комбинаций в движке,
результат шейдеров и изменение FPS не проверялись. Совместимость с будущими
версиями GAMMA и библиотек требует повторной проверки. Контрольные суммы ZIP
и результат проверки CRC находятся в `dist/SHA256SUMS.txt` и `dist/validation.json`.
