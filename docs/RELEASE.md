# Кандидат BLACK SIGNAL 0.1.0-rc.1

Название: **BLACK SIGNAL — by @Flixmo**.
Планируемый репозиторий: `vobelo571/black-signal`. Публикация не выполнялась.

## Материалы релиза

- Общий FOMOD ZIP с выбором 28 компонентов, без обязательных игровых модулей.
- 28 отдельных ZIP; общий пак для их установки не нужен.
- Отдельные исходники SaveReset и CustomMods.
- Готовый SaveReset для Windows x64 отдельным ZIP (собран из сохранённых исходников .NET 8).
- Каталог модулей, внешних зависимостей, авторов и контрольных сумм.

## Проверки

`python tools/validate.py` проверяет состав, ссылки зависимостей внутри реестра,
XML, отсутствие конфликтующих путей между модулями, отсутствие приватных
сейвов/логов/музыки, соответствие исходным хешам и предел размеров файлов.

`python tools/validate.py --archives` дополнительно открывает и проверяет CRC
каждого ZIP, структуру каждого отдельного модуля, контрольные суммы и соответствие
файлов установщика всем компонентам. FOMOD содержит выбор SelectAny / Optional.

Результаты текущего запуска: `dist/validation.json`. Lua-проверка и отдельная
проверка пустого плейлиста отражаются в `docs/QA.md`, когда выполнены.

## Перед публичным выпуском

1. Подтвердить право повторного распространения производных/заимствованных
   ресурсов из RIGHTS.md либо вынести их в внешние зависимости/патчи.
2. Проверить в MO2 открытие мастера и установку минимального, выборочного и
   полного набора. Файловая имитация установки не заменяет реальный мастер MO2.
3. На копии сейва проверить загрузку, меню, RF, торговцев, проводника, Taskboard,
   сохранение/перезагрузку снаряжения и NPC. Игровой тест всей интеграции ещё не выполнен.
4. Выбрать окончательный статус prerelease и описание, затем создать репозиторий.

## Публикация после обзора

Локальная Git-история подготовлена отдельно от игрового `mods`. Рабочая игра
не переключается на этот пак автоматически.

При установленном GitHub CLI и входе в аккаунт владельца:

```powershell
gh repo create vobelo571/black-signal --public --source . --remote origin --push
gh release create v0.1.0-rc.1 dist/*.zip dist/SHA256SUMS.txt --prerelease --title "BLACK SIGNAL 0.1.0-rc.1 — by @Flixmo" --notes-file docs/RELEASE_NOTES.md
```

Эти команды создают публичный репозиторий и релиз. В рамках подготовки они
не запускались. Не загружайте `dist/` в Git: архивы предназначены для Releases.
